## 系数与适用限制

在峰归属及局部线性假设下，令 `E_keV = p0 + p1 * energy_ch`：
`p1 = (E2 - E1) / (x2 - x1)`，`p0 = E1 - p1 * x1`，`p2 = 0`。

| 通道 | nominal p0 / keV | nominal p1 / (keV/ADC) | 三种区间的 p0 范围 / keV | 三种区间的 p1 范围 / (keV/ADC) |
| --- | ---: | ---: | ---: | ---: |
| 2 | −4.48886 ± 0.27461 | 1.960150 ± 0.000429 | −4.64339 至 −4.17742 | 1.959670–1.960429 |
| 3 | −17.70566 ± 0.27950 | 1.061668 ± 0.000234 | −17.95060 至 −17.56823 | 1.061578–1.061838 |

系数协方差由两峰峰位及参考能量的不确定度传播得到。转换宽度时还保留每个峰的
峰位/宽度协方差，以及斜率与宽度的相关性。两个不相交区间的峰拟合、两条参考线能量
均按相互独立处理；参考能量之间可能存在的相关性未建模。输出中名为 `*_stat_error`
的刻度/keV 宽度误差含参考能量标准不确定度，但不含模型及区间选择的系统不确定度。

| 通道 | 候选参考能量 / keV | nominal FWHM / keV | FWHM / 参考能量 / % |
| --- | ---: | ---: | ---: |
| 2 | 1173.228 | 21.8691 ± 0.0849 | 1.86401 ± 0.00724 |
| 2 | 1332.492 | 23.1673 ± 0.0885 | 1.73865 ± 0.00665 |
| 3 | 1173.228 | 20.8857 ± 0.0908 | 1.78019 ± 0.00774 |
| 3 | 1332.492 | 22.2319 ± 0.0942 | 1.66845 ± 0.00707 |

这些宽度是指定局部峰模型和两点映射下的条件结果。通道 2 的 nominal 低能峰已触发
模型检查提示；扩大范围后，通道 2/3 低能峰的 deviance/ndf 分别升至 **4.770 / 4.463**，
提示常数背景或峰形不足。区间跨度是敏感性检查，不能直接充当系统误差估计。

两条参考线恰好确定两个系数，刻度自由度为 **0**。本次未检验 1173.228–1332.492 keV
区间内的线性，更未验证区间外的外推。`linearity_validated=false`、
`status=candidate_requires_review` 随每组系数保存；未生成或覆盖八通道 `.dat`。
六份历史参数及其来源状态保持原样，见[参数来源登记](parameter-provenance.md)。

下一步先比较低能峰的背景斜率及峰尾模型，检查残差和系数稳定性；正式采用前还需独立
能量参考或其他线性证据，明确对应探测器与测量条件。现有信息不足以给其他通道补刻度，
也不足以把本次系数推广至 DT5720 run_4 或历史 PHA 数据。
